# Animal Arena — Frontend

React + TypeScript + Vite + Tailwind CSS frontend for Animal Arena.

See the [project root README](../README.md) for the full write-up
(architecture, simulation methodology, setup, API reference) and
[docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md) for how this app talks to
the backend.

## Quick start

```bash
npm install
cp .env.example .env.local   # point at your backend, defaults to localhost:8000
npm run dev
```

## Scripts

- `npm run dev` — start the Vite dev server
- `npm run build` — type-check (`tsc -b`) and build for production
- `npm run preview` — preview the production build locally
- `npm run lint` — run oxlint
